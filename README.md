# Привет, я Михаил

Вайбкодер, который собирает **внутренние продукты под реальный процесс**: оценка залогов, операционные платформы. Не пет-проекты «ещё один TODO» — сервисы, которыми пользуются коллеги.

Стек: **Python (FastAPI)**, **Java / Spring Boot**, немного **PHP** там, где хостинг не тянет базу.

## Что умею

- Спроектировать доменную модель и довести её до UI, которым пользуются не разработчики
- Нормализация грязного рынка: марки, модели, выбросы цены, единый датасет для оценки
- Excel-контуры под методику — когда PDF из шаблона важнее красивого SPA
- Быстро собрать рабочий сервис: FastAPI + async + выгрузка, без лишнего фреймворка
