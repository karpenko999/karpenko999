# Привет, я Михаил

Инженер, который собирает **внутренние продукты под реальный процесс**: оценка залогов, рынок техники, кадастр, операционные платформы. Не пет-проекты «ещё один TODO» — сервисы, которыми пользуются коллеги.

Сейчас собираю портфолио для хакатона и открытых задач. Стек: **Python (FastAPI)**, **Java / Spring Boot**, немного **PHP** там, где хостинг не тянет базу.

## Что умею

- Спроектировать доменную модель и довести её до UI, которым пользуются не разработчики
- Парсинг и нормализация грязного рынка (Avito / Drom) с чекпоинтами, а не «один скрипт на коленке»
- Excel-контуры под методику (СП МiО, ЕНАО, пакеты РМ) — когда PDF из шаблона важнее красивого SPA
- Быстро собрать рабочий сервис: FastAPI + async + выгрузка, без лишнего фреймворка
